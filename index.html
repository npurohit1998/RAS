📖 Setup Guide
Step 1 — supabase.com पर जाएं → Free account बनाएं
Step 2 — New Project बनाएं (कोई भी नाम, Password याद रखें)
Step 3 — बाईं तरफ SQL Editor → New Query → नीचे दिया गया SQL पेस्ट करके Run करें: 
create table rpsc_questions (id text primary key, questions jsonb, updated_at timestamptz);
create table rpsc_syllabus (id text primary key, data jsonb, updated_at timestamptz);
create table rpsc_progress (id text primary key, data jsonb, updated_at timestamptz);
alter table rpsc_questions enable row level security;
alter table rpsc_syllabus enable row level security;
alter table rpsc_progress enable row level security;
create policy "public access" on rpsc_questions for all using (true) with check (true);
create policy "public access" on rpsc_syllabus for all using (true) with check (true);
create policy "public access" on rpsc_progress for all using (true) with check (true);
Step 4 — बाईं तरफ Project Settings → API जाएं → Project URL और anon public key कॉपी करें
Step 5 — ऊपर दोनों बॉक्स में पेस्ट करके "कनेक्ट करें" दबाएं
